# Java Calculator

A simple command-line calculator built in Java that supports +, -, *, /, % and exits on x/X.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division, modulus
- Runs continuously in a loop, so you can perform multiple calculations without restarting
- Handles invalid input gracefully (unrecognized operators)
- Prevents division/modulus by zero with a clear error message
- Type `x` or `X` to exit the program

## Operators Supported

|--------|----------------|
| `+`    | Addition       |
| `-`    | Subtraction    |
| `*`    | Multiplication |
| `/`    | Division       |
| `%`    | Modulus        |
| `x`/`X`| Exit program   |

## About This Project

This is a beginner Java project built while learning core concepts like loops, conditionals, input handling with `Scanner`, and basic error handling.
